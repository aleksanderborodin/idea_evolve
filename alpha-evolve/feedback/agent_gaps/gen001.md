# Agent Gaps — Generation 1

## Cross-Agent Observations

### 1. explore_1 and explore_2 duplicated effort
Both agents independently discovered multi-seed restart and converged to similar
scores (1.5155 and 1.5182). Neither tried smooth-max, which was the actual
breakthrough (from full_1). Better coordination: one explore agent should test
algorithmic innovations, the other should test representation changes.

### 2. Research findings not used by coding agents
research_1 produced excellent findings about coarse-to-fine with simulated annealing
(Boyer et al.), the AlphaEvolve function array, and the arcsine distribution
initialization. None of these were used by the coding agents because research ran
concurrently (not before) the coding agents. In gen 2, research findings should
be available in briefs.

### 3. No agent visualized the optimized function
Multiple agents noted they lacked knowledge of "what the optimized function looks
like." No agent ran a visualization. Understanding the shape of the best solution
(sol03) would inform initialization strategies for gen 2.

### 4. explore_2 claim about Lion may be overstated
explore_2 report states "Lion > Adam for this objective." However, sol09 (Lion+Adam,
1.5182) matches sol04 from explore_1 (pure Adam 80k, 1.5182). The improvement
may be from multi-seed, not Lion. This should be tested as a controlled experiment.

### 5. No agent tried simulated annealing
Despite research_1 strongly recommending it based on Boyer et al., no coding
agent implemented a simulated annealing wrapper. This is the highest-priority
gap for gen 2.

### 6. Fourier-basis parameterization underexplored
explore_2/sol04 tried Fourier basis but scored 1.5294 — mediocre. However,
it was not combined with smooth-max. Research findings suggest Fourier
parameterization could reduce dimensionality (20 parameters vs 600).

### 7. explore_1/sol07 was unevaluated by its agent
sol07 (32 seeds, 16 modes) was left unevaluated due to timeout. The agent
ran out of time on its most ambitious solution. Score was 1.5157 — good
but not dramatically better than sol05 (1.5155), suggesting 32 seeds
provides minimal benefit over 8.
