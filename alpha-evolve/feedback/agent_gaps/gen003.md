# Agent Gaps — Generation 3

## Knowledge Gaps

1. **explore_1 lacked SA calibration data.** The agent didn't know typical C differences between neighboring basins (~0.001-0.005), leading to over-high Metropolis temperatures. A short calibration phase (5 iterations to measure acceptance rate) should be standard protocol for any SA approach.

2. **explore_1 didn't know about population/best.py.** The AlphaEvolve solution was already in the population as best.py, but explore_1's brief didn't mention it. The agent only discovered it during the session, too late to use. State of Affairs should list the path to best.py and its score.

3. **exploit_1 lacked the exact raw_params from gen002.** Without the intermediate optimized arrays, the agent couldn't warm-start from the exact 1.5091 basin — it had to re-derive from scratch, getting 1.5094 (not 1.5091). Future exploit agents should receive the actual serialized arrays from the best prior solutions.

4. **No agent implemented warm-start from the AlphaEvolve solution.** research_1 retrieved it, explore_1 discovered best.py too late, exploit_1 didn't have it in the brief. This was the highest-leverage experiment and was completely missed by the coding agents.

## Pipeline Gaps

5. **The "Boyer et al. N=23 coarse SA" recommendation was based on incorrect attribution.** Multiple agents and the State of Affairs recommended this as AlphaEvolve's approach, but research_1 discovered it's from a different paper. AlphaEvolve used LP-guided gradient + SA at full resolution. This misdirected explore_1's entire session.

6. **Intermediate optimized arrays are not persisted.** Agents optimize in raw-param space, convert to f-values, evaluate, and discard the raw_params. Without saved raw_params, exploit agents cannot warm-start from prior basins. Saving the raw_params arrays (not just the final f-values) would significantly help exploit agents.

7. **Research agent produced the single highest-impact result but had lowest priority.** The research_1 retrieval of C=1.5032 is by far the most impactful action this generation — yet it was just one solution from one agent type. The pipeline should ensure research findings feed immediately into coding agent briefs.

## Contradictions

8. **explore_2 claims arcsine is "superior"** but the improvement is 0.0001 (1.5090 vs 1.5091). This may be within noise. A 50-seed controlled experiment is needed before promoting arcsine to established. Confidence set to 0.55.

9. **explore_1 claims SA at coarse scale is a "dead end"** based on 3 poorly calibrated runs. The technique itself may still be viable with proper temperature calibration. Not debunked, but requires better experimental design.

- **Priority 2:** Retrieve additional published solutions (ThetaEvolve, Yuksekgonul 2026).
