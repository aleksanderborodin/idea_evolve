# Agent Gaps — Generation 7

## Gap 1: Triplet strategy breakdown not logged

explore_1 rotated 4 triplet selection strategies but did not log which strategy produced
which improvements. Breaking down the 160 improvements by strategy type would identify the
most productive structural approach and focus future triplet searches. This is low-cost
instrumentation that should be mandatory in the next triplet agent's brief.

## Gap 2: No interleaving of coordinate descent and triplet perturbation

All gen 7 agents used either coordinate descent OR triplet perturbation, never both in
sequence. Triplet improvements may unlock new single-element improvements (changing the
autoconv landscape), and vice versa. No agent tested this interleaving hypothesis.

## Gap 3: Coordinate descent convergence inconsistency

exploit_1 reports 6551 improvements over 6 rounds starting from gen006 best.
exploit_2 reports only 156 improvements over 3 rounds from the SAME starting point.
full_1/sol04 reports 257 improvements over 2 rounds. The different improvement counts
suggest different delta grids or different orderings of element scans. Without standardized
delta grids, convergence claims are hard to compare across agents.

**Recommendation:** Use the new `incremental_autoconv_update` helper with a standardized
delta grid to ensure reproducible coordinate descent results.

## Gap 4: LP intermediate resolution untested

full_1 tried N=2000 (too coarse, C=1.721 at that resolution) and N=30000 (plateau problem).
The range N=5000-10000 was never tested. At intermediate resolution, the plateau may have
fewer near-max points, making LP more tractable, while the direction may transfer better
to N=30k than the N=2000 direction did.

## Gap 5: Autoconvolution plateau structure undocumented

exploit_1 discovered that the autoconvolution has 15384 positions within 1e-10 of the max
and a gap of ~7e-21 between 1st and 2nd position. full_1 found ~6500 within 1e-7*max.
This structural information is critical for understanding LP feasibility but was not
captured in any idea or fact file. Pattern_013 now documents this, but a dedicated
fact about the plateau structure would be useful.

## Gap 6: Experimentator helpers not used by gen 7 agents

The experimentator delivered 3 new helpers (incremental_autoconv_update, cross_convolution_f64,
lp_matrix) during gen 7, but no gen 7 agent could use them because they were deployed
simultaneously. All agents reimplemented the incremental update from scratch. These helpers
will save time starting in gen 8.

## Gap 7: pattern_007 duplicate file still exists

active/pattern_007.md (gen 4, confidence 0.85) still exists alongside
confirmed/pattern_007_update.md (gen 6, confidence 0.95). The consistency review flagged
this in gen 6 and the architect noted it in gen 7, but it remains unfixed. Low impact
since no agent uses smooth-max Adam anymore, but it's knowledge hygiene debt.

## Gap 8: fact_002 still outdated

fact_002 states "best known bounds 1.28 ≤ C ≤ 1.5098, target C ≤ 1.5053." Current best
is C = 1.50286, target beaten since gen 3. Multiple agents have flagged this across gens 6-7.
Should be updated to reflect current SOTA.
