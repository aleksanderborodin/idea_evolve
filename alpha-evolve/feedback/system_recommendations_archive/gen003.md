## Priority 8 — Fix SA sigma formula in agent templates

**What to change:** In `agents/explore.md` (and any other template that mentions SA sigma), replace:
- Remove: `sigma = 0.3 * mean(|f|)`
- Add: `sigma = min(0.05 * mean(|f|), 1.0)  # cap prevents runaway perturbations`

And add the calibration step:
```
After setting sigma, run 5 trial SA steps. Measure acceptance rate.
Target: 20-40%. If acceptance > 70%, halve sigma. If < 10%, double sigma.
```

**Why:** The 0.3 formula was used in all failed SA implementations. At N=80, mean(f) ≈ 20-40 → sigma = 6-15 → perturbation scale randomizes the entire solution. The 5-trial calibration catches this immediately.

**Expected impact:** Eliminates the systematic SA calibration failure mode. SA at coarse scale remains promising with proper calibration.
