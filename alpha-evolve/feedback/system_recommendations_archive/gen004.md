## Priority 4 — Create three helpers before Gen 5 launches

Three helpers were requested by multiple agents (2-4 independent requests each). These should
be created by the Experimentator and validated before Gen 5:

### Helper A: `inv_softplus_safe(array)` (HIGH — 4 requests)
```python
def inv_softplus_safe(f, eps=1e-8):
    """Inverse softplus: maps f (non-negative) to raw_params for Adam.
    Handles near-zero values safely (no large negatives that freeze gradients).
    Use eps > 0 to prevent log(0) and gradient vanishing at near-zero f.
    Clip raw_params to [-10, 30] to prevent frozen gradients in Adam.
    """
```
**Why:** All exploit agents implemented this ad hoc with varying epsilon handling. The near-zero
freezing problem (softplus gradient → 0 for f ≈ 1e-7) is the root cause of pattern_007
failures. A canonical helper with proper clipping prevents this class of bug.

### Helper B: `sensitivity_map(f_array)` (HIGH — 5 requests across gens)
```python
def sensitivity_map(f_array):
    """Compute dC/df[i] for all elements using JAX autodiff.
    Returns gradient array of same shape as f_array.
    Identifies which elements are most amenable to optimization.
    """
```
**Why:** Five agents across three generations have wished for this. It's a 5-line JAX computation
but every agent reimplements or skips it. Having a canonical helper enables sensitivity-guided
coordinate descent experiments across multiple agents simultaneously.

### Helper C: `interpolate_sparse(array, target_n)` (MEDIUM — 3 requests)
```python
def interpolate_sparse(array, target_n, threshold=1e-4):
    """Upsample array to target_n, preserving near-zero structure.
    Non-zero regions: piecewise-linear interpolation.
    Regions below threshold: set to 0.0 (not interpolated through).
    Prevents cubic spline artifacts in sparse arrays.
    """
```
**Why:** exploit_2 gen4 used cubic spline and got C=1.5159 (0.013 worse). The correct
interpolation for sparse arrays preserves zero-region structure. Multiple agents mentioned this.

**Expected impact:** Each helper saves 5-15 turns per agent that would otherwise reinvent or
debug these operations. Sensitivity-guided experiments become feasible as a one-liner.
