For the Experimentator and Architect. Ordered by expected information gain.

## Experiment 1: Coarse-scale SA + Upsampling (Boyer et al. Approach)

**Hypothesis:** SA at the coarse grid (N=30-50) finds qualitatively different basins than SA at N=600. The low-dimensional coarse landscape has fewer local minima and cheaper function evaluations, allowing meaningful exploration before the expensive fine-tuning phase.

**Design:**
- Optimize at N=30 (or N=50) with smooth-max (T=0.05→0.01→0.003, 5k steps each)
- Run 20-40 SA iterations at coarse scale: sigma = 0.3 × mean(|f|), inner optimizer = smooth-max Adam (T=0.05→0.01, 5k steps), acceptance temperature targeting ~30-40% acceptance rate
- Log acceptance rate every 10 SA iterations (diagnostic)
- Upsample best coarse solution to N=600 via jnp.interp
- Run standard warm smooth-max fine-tuning (T=0.05→0.01→0.003→0.001→0.0003, 15k steps each)

**What to measure:**
1. Do different SA trajectories at N=30 converge to different fine-stage basins at N=600?
2. What acceptance rate does sigma=0.3×mean(|f|) achieve? (Tune if < 10% or > 70%)
3. Does the fine stage after upsampling reach below 1.5091?

**Expected outcomes:**
- Best case: find basin below 1.509 (Boyer et al. reached ~1.503 with this approach)
- Null case: same sticky basin at N=30, all paths → same 1.5108 region after upsampling
- Information value: High in both cases. Success confirms the path to target. Null case means the problem is in the coarse landscape structure, not the fine-tuning.

**Budget estimate:** 40 SA iterations × 10k inner steps = 400k coarse steps (~130s at 3k steps/sec) + 75k fine steps (~25s). Well within 600s for 1-2 seeds. Can run 4-6 seeds.

## Experiment 2: Warm-Start Polish from gen002_explore_1_sol03 (C=1.5091)

**Hypothesis:** The 1.5091 solution is not at a strict local minimum of the warm smooth-max objective — extended low-temperature annealing may continue improving it.

**Design:**
- Load gen002_explore_1_sol03's output array via `entrypoint()` (or save/load the raw JAX array)
- Run 3 additional fine-annealing phases: T=0.0003→0.0001→0.00003, 50k steps each (150k total new steps)
- Compare to loading the gen1 best (1.5108) and running the same schedule — does starting from 1.5091 give a meaningful advantage?

**What to measure:**
1. Does score improve below 1.5091 with extended low-T annealing?
2. Is the improvement proportional to starting point (1.5091 vs 1.5108 warm-starts)?

**Expected outcomes:**
- Best case: 1.507-1.505 range, confirming that low-T annealing still has gradient to exploit
- Null case: score stays at 1.509±0.001, confirming the solution is at a local minimum
- Information value: High — directly tests whether the 1.5091 solution is fully converged

**Budget estimate:** 150k steps × 1 solution = ~50s. Very cheap. Can run with 4 seeds.

## Experiment 3: Coarse Resolution Sweep for Optimal N

**Hypothesis:** The choice of coarse resolution N affects how much basin diversity survives upsampling to N=600. There exists an optimal N that balances exploration quality (higher N = more information) vs. speed (lower N = more SA iterations per budget).

**Design:**
- Test N ∈ {20, 30, 50, 80, 120} at coarse stage
- For each N: 8 random restarts, warm smooth-max (T=0.1→0.05→0.01→0.003, 8k steps each), upsample to N=600, warm fine-tuning (T=0.05→0.01→0.003→0.001, 15k steps each)
- No SA — pure coarse-to-fine with varying N

**What to measure:**
1. Best score achieved at N=600 fine stage for each coarse N
2. Variance across 8 seeds — does coarse N affect how "funneled" the fine stage is?
3. Wall clock time per restart at each N

**Expected outcomes:**
- N=20 too coarse: insufficient basin information, high variance
- N=120 too expensive: fewer SA iterations per budget
- Sweet spot likely N=40-80 (gen2 explore_1 found N=80 > N=40)
- Information value: Medium-high. Calibrates the primary hyperparameter for coarse-to-fine experiments.

**Budget estimate:** 5 resolutions × 8 seeds × ~60k steps = ~2.4M steps. This is 2-3 agent runs worth of compute. Recommend running N=20, 50, 120 first (3 values), then sweeping the gap.

## Experiment 4: Non-Gaussian Coarse Initialization Zoo

**Hypothesis:** The Gaussian-bump initialization family all funnel to the same ~1.5108 basin. Structurally different initializations (multi-peaked, comb-like, step functions, arcsine-distributed) may find qualitatively different basins that survive upsampling to N=600.

**Design:**
- At N=80 coarse stage, try each initialization family (4-8 seeds each):
  a. Gaussian bumps at random positions (current baseline)
  b. Comb function: f(x) = sum of narrow peaks at evenly-spaced positions
  c. Arcsine-weighted: f(x) ∝ 1/sqrt(x(1-x)) (from literature)
  d. Random step function: piecewise constant with random heights
  e. Half-domain support: f=0 for x<0.5, random smooth for x>0.5
- Run warm smooth-max at coarse stage, upsample to N=600, warm fine-tuning
- Compare best score and score distribution across initialization families

**What to measure:**
1. Do any initialization families find basins below 1.509 at N=600?
2. Is there a family that produces lower variance across seeds?

**Expected outcomes:**
- Null case: all families funnel to same basin, confirming stickiness is in the landscape structure not initialization
- Positive case: arcsine or comb initialization finds C < 1.509, suggesting the known-good solution has structural properties we can seed
- Information value: Medium. Cheap to run, directly tests a well-identified gap.

**Budget estimate:** 5 families × 6 seeds × 2-stage = ~600k steps (~200s). 1 agent run.

## Experiment 5: AlphaEvolve Warm-Start Retrieval

**Hypothesis:** AlphaEvolve published a 600-interval solution at C=1.5032. Loading this array as initialization for our optimization pipeline would immediately provide a warm-start below our current best.

**Design:**
- Search for and retrieve the AlphaEvolve solution array from the published paper or repository
- Load it as the initial condition for warm smooth-max fine-tuning (T=0.01→0.003→0.001→0.0003, 30k steps each)
- Measure: does further optimization improve it, maintain it, or regress it?

**What to measure:**
1. Is the array retrievable from public sources?
2. Does our optimization pipeline maintain C≈1.503 from the AlphaEvolve starting point?
3. Can we push below 1.503 from this starting point?

**Expected outcomes:**
- Best case: retrieve array, confirm C=1.5032, push to C<1.503 with further optimization
- Retrieval failure: rules out this approach cleanly
- Regression: suggests our smooth-max objective has different landscape properties than AlphaEvolve's objective (important diagnostic)

**Information value:** Very high if successful. Essentially free progress toward the target.

## Experiment 6: Structured Fourier Perturbations for Basin Hopping

**Hypothesis:** Random Gaussian perturbations in the pointwise function values don't effectively explore the solution landscape because they destroy the frequency structure of the function. Perturbing Fourier modes (adding random phase shifts to dominant modes) may explore more efficiently.

**Design:**
- Take best solution (1.5091), compute its DCT/FFT
- Apply structured perturbations: shift the phase of modes k=1 through k=20 by random amounts (|Δφ_k| ~ Uniform[0, π/4])
- Run 30 perturbations × warm smooth-max (T=0.05→0.01→0.003, 20k steps each) = 600k steps
- Compare: does any perturbed version reach below 1.509?

**What to measure:**
1. Do Fourier perturbations find diverse basins (variance in fine-tuned scores)?
2. Does any perturbation find C < 1.509?

**Expected outcomes:**
- Positive: some Fourier perturbations find C < 1.509, validating frequency-domain exploration
- Null: all perturbations return to the same basin, suggesting the problem is in the landscape, not the perturbation strategy
- Information value: Medium. Novel exploration strategy not yet tried.

## Experiments to NOT Run (Confirmed Dead Ends)

- Fine-grid SA (N=600): three gen2 solutions, conclusively ineffective
- L-BFGS polish after smooth-max convergence: four gen2 solutions, zero benefit
- More restarts on standard approach: 20 restarts = 1.5108, same as 8 restarts
- Extended temperature schedule (adding T=0.0001 phase): no benefit
- Periodic normalization with optimizer reset: destructive to optimization progress
- Gradient clipping combined with normalization: negative effect observed
