## Experiment E1 — Warm-start smooth-max from AlphaEvolve array (C=1.5032)

**Priority: CRITICAL**

**What to test:**
Load `population/best.py` (the 1319-element AlphaEvolve array). Convert to raw_params via `inv_softplus(f)`. Run warm smooth-max Adam with a tight temperature schedule: T=0.005→0.002→0.001→0.0003→0.0001, 20-30k steps per stage. Try 4-8 seeds with different noise realizations around the starting point (small perturbations of raw_params, sigma=0.01).

**Hypothesis:**
The AlphaEvolve algorithm used LP-guided gradient descent with SA perturbations, NOT smooth-max temperature annealing. Our smooth-max pipeline may navigate the local landscape differently. Starting from the 1.5032 basin (far better than our ~1.509 basin), smooth-max may find further local improvements that LP-guided gradient couldn't reach.

**Expected information gain:**
If smooth-max pushes below 1.503: confirms the two algorithms are complementary and warm-start + smooth-max is the primary strategy.
If smooth-max stays at ~1.5032: confirms the basin is already fully converged and we need qualitatively different approaches (LP-guided gradient, different parameterization).

**Success criterion:** C < 1.503 from at least one seed.

**Agent type:** exploit_1

## Experiment E4 — SA at N=23 with proper calibration

**Priority: MODERATE**

**What to test:**
Implement coarse-scale SA at exactly N=23 (the scale Boyer et al. used). Key implementation requirements:
1. Run 5 calibration SA steps before the main run. Measure acceptance rate. Tune metro_temp to achieve 20-40%.
2. sigma = min(0.05 * mean(|f|), 1.0) — capped to prevent runaway perturbations.
3. 1000 SA iterations × 300 inner steps each.
4. Upsample best coarse to N=600, run warm smooth-max (T=0.05→0.0003).
5. Run 4 independent seeds.

**Hypothesis:**
All prior SA attempts used N=30-80. At N=23, there are only 23 degrees of freedom, meaning the coarse landscape has far fewer local minima and SA can hop between fundamentally different solution structures. This is the scale Boyer et al. found effective.

**Expected information gain:**
If N=23 SA finds sub-1.509 basins after fine-tuning: confirms the technique is valid with proper calibration and the N=30-80 range was simply the wrong scale. If N=23 also fails: the coarse-SA approach is genuinely ineffective for this problem, not just miscalibrated.

**Success criterion:** At least one SA seed finds a basin that fine-tunes to C < 1.509 (better than current gradient-descent floor).

**Agent type:** explore_1 or experimentator

**Priority: MODERATE**

**What to test:**
Fix the winning arcsine configuration from Gen 3 (a=-0.05, b=0.22, tilt=0.1→0.5) and run 50 independent seeds with the 2-stage coarse-to-fine pipeline. Record the distribution of final C values.

**Hypothesis:**
Gen 3 explore_2 found C=1.508974 with arcsine init. This may be either:
(a) A genuinely better basin that arcsine reliably finds (mean C ≈ 1.509 with small variance)
(b) A lucky noise realization that isn't reproducible (mean C ≈ 1.510 with high variance)

The noise-key sensitivity observed in explore_2 (same config: 1.508974 to 1.553228) suggests (b) is likely. If the mean is 1.509x with std < 0.001, arcsine is genuinely better. If the distribution is bimodal (1.509x and 1.52+), arcsine just finds the same basin as Gaussian but with higher hit rate.

**Expected information gain:**
Determines whether arcsine init should be elevated to `established` (if consistently better) or remain `active` with low confidence (if the improvement is noise). Directly controls whether future agents should use arcsine as the default.

**Success criterion:** 50-seed distribution summary with mean, std, and fraction of runs reaching C < 1.510.

**Agent type:** experimentator

## Experiment E6 — LP-guided gradient direction (AlphaEvolve's actual algorithm)

**Priority: LOWER (research effort, high implementation complexity)**

**What to test:**
Implement the `solve_convolution_lp` direction-finding step from the AlphaEvolve notebook. The algorithm:
1. Compute the autocorrelation constraint gradient
2. Solve a small LP to find the steepest descent direction
3. Run a cubic backtracking line search along that direction
4. Add SA perturbations when the LP solution stagnates

**Hypothesis:**
AlphaEvolve's LP-guided gradient provably finds the steepest descent direction in the constraint surface, which may differ significantly from Adam's gradient in the smooth-max landscape. The LP formulation can also find descent directions even when smooth-max gradients are numerically flat.

**Expected information gain:**
If LP-guided gradient improves on our current best: confirms that smooth-max Adam is the bottleneck and we should combine LP-guided + smooth-max. If it matches our current best: the bottleneck is initialization (finding good basins), not optimization within basins.

**Success criterion:** Implement and run LP-guided on our current best initialization. Compare with Adam+smooth-max on same seeds.

**Agent type:** full (high complexity; needs both implementation and evaluation) or a dedicated exploit agent

## Experiment E7 — Coordinate descent + sensitivity mapping on the AlphaEvolve solution

**Priority: LOWER (analytical, low compute)**

**What to test:**
Take the 1319-element AlphaEvolve array. For each element i, independently perturb f[i] by ε=0.01 and re-evaluate C. Map the sensitivity (∂C/∂f[i]) across all elements. Identify the 10-20 most sensitive elements.

**Hypothesis:**
The AlphaEvolve solution's complex structure (dense first 25 elements, gap, multi-peak) has highly non-uniform sensitivity. Some elements contribute much more to C than others. Knowing which elements are most sensitive informs:
(a) Where to focus warm-start perturbations
(b) Which structural features are load-bearing vs incidental
(c) Whether coordinate descent on high-sensitivity elements can find improvements

**Expected information gain:**
A sensitivity map of the best known solution. This is purely analytical — even if it doesn't directly improve the score, it informs all future exploitation strategies.

**Success criterion:** Sensitivity array produced and top-20 high-impact elements identified.

**Agent type:** experimentator (cheap to run, purely analytical)
