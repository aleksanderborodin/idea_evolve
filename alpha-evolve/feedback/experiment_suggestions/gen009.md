## Experiment 2: Optimization Sequence A/B Test

**Priority: HIGH — determines gen 10 standard protocol**

**What to do:**

Two parallel agents, both starting from gen 9 best (C = 1.5028628682228971):

**Path A (control):**
1. Ultra-fine coordinate descent only
   - Delta grid: `np.geomspace(1e-11, 1e-1, 50)`, plus reverse negatives
   - Run until no improvement in a full round
2. Record final C

**Path B (test):**
1. Triplet perturbation: 100k trials, all 4 strategies
2. Quadruplet perturbation: 20k trials
3. Ultra-fine coordinate descent (same delta grid as Path A)
4. Record final C

**Hypothesis:** pattern_020 suggests ultra-fine CD subsumes multi-element moves. If Path A ≈
Path B, confirm the pattern and simplify future protocols to "just run ultra-fine CD."
If Path B > Path A (lower C), the ordering matters and multi-element moves should precede
ultra-fine CD.

**Expected information gain:**
- If Path A wins or ties: protocol simplified, ultra-fine CD is sufficient
- If Path B wins: the optimal sequence is confirmed as [multi-element] → [ultra-fine CD],
  and future agents should be briefed accordingly. Potential gain: ~1e-10 per generation

**Estimated cost:** 2 agent sessions (~$1–2), ~30–60 min each.

**Priority: HIGH — determines whether we are at the precision floor**

**What to do:**
1. Start from gen 9 best
2. Run coordinate descent with `np.geomspace(1e-14, 1e-1, 100)` as delta grid
3. Track improvements found at each decade: 1e-7 to 1e-8, 1e-8 to 1e-9, ..., 1e-13 to 1e-14
4. Plot improvements vs. delta scale

**Hypothesis:** exploit_1's Pass 3 (1e-11 to 5e-11 scale) found 375 improvements. If
improvements continue at 1e-12 and 1e-13 scales, the solution is not at the float64 floor.
If improvements drop to zero at 1e-12, we have found the practical precision limit.

**Expected information gain:**
- If improvements exist at 1e-12: potentially 1–3 more generations of meaningful improvement
- If zero improvements at 1e-12: confirms we are at the float64 floor; convergence criterion
  should trigger at ~1e-11

**Estimated cost:** 1 exploit agent session, ~30–45 min.

## Experiment 4: plateau_analyzer Tool Validation + Minimax Triplet Prototype

**Priority: MODERATE — addresses Pattern_020 paradox**

**What to do:**

**Phase 1 (Experimentator task):** Build and deploy `plateau_analysis()` helper. See
Priority 7 in system_recommendations.md for the function spec.

**Phase 2 (Exploit agent):** Using the new helper:
1. Compute plateau structure of gen 9 best
2. If len(positions) > 1 at threshold 1e-12: implement minimax triplet perturbation
   - For each candidate triplet (i, j, k), compute gradient at ALL plateau positions
   - Find the direction (d1, d2, d3) with d1+d2+d3=0 that minimizes max(gradient·delta)
   - This is a small LP: 3 variables, len(positions) constraints
3. Run 50k minimax triplet trials and compare to standard triplet improvement rate

**Hypothesis (idea_023):** With 13+ plateau positions, standard single-peak gradient
misses descent directions that reduce all near-peak values. A minimax direction reduces the
binding constraint across all plateau positions simultaneously and may find improvements
where standard triplets find none.

**Expected information gain:**
- If minimax triplets work: new improvement avenue opens, potentially unlocking multi-element
  moves again after ultra-fine CD
- If minimax triplets also fail: confirms the solution is a genuine local minimum for
  all 3-element perturbations regardless of gradient strategy. Combined with Experiment 3
  approaching float64 limits, this would justify declaring convergence.

**Estimated cost:** Experimentator session (helper build, ~30 min) + 1 exploit session
(minimax test, ~45 min).
