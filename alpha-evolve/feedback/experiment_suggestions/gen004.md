## Experiment 1 — Projected Gradient Descent on TTT-Discover 30k Array

**Priority: CRITICAL**

**What to test:**
Load the TTT-Discover 30k array (population/gen004/research_1/sol01.py, C=1.50286). Optimize f
directly (NOT softplus-parameterized raw_params). After each Adam step, project with:
`f = jnp.maximum(f, 0.0)`. Use very conservative learning rate (1e-5 to 1e-6). Either:
- Option A: Optimize the true objective (max of autoconvolution sum) without smoothing
- Option B: Use smooth-max at T=0.0001 only (much colder than the failed T=0.005 attempts)

Run 20k-50k steps with LR warmup (start at 1e-7, ramp to 1e-5 over 1k steps).

**Hypothesis:**
The softplus parameterization freezes near-zero elements (gradients → 0). Direct f-space
optimization with projection eliminates this dead-zone problem. The TTT-Discover array has
many near-zero elements that smooth-max Adam couldn't move. Projected gradient descent should
be able to move these elements and potentially find a lower C.

**Expected information gain:**
- If it improves C: We've found the first agent-driven improvement over a published solution.
  Direct f-space optimization becomes the primary exploit strategy.
- If it doesn't improve C: The 1.50286 basin is flat in f-space (not just in softplus space).
  LP-guided methods are the only viable optimization approach. We should focus entirely on
  retrieval and LP reimplementation.

**Success criterion:** C < 1.50286 (any improvement counts, even 1e-5).
**Failure criterion:** C ≥ 1.50280 after 50k steps (better than current best by noise level only).

## Experiment 2 — Coordinate Descent on TTT-Discover 30k Array (Sensitivity-Guided)

**Priority: HIGH**

**What to test:**
1. Compute ∂C/∂f[i] for all 30k elements using JAX autodiff (fast — evaluate.py uses FFT).
2. Sort elements by |gradient| descending.
3. For the top-500 most sensitive elements: try f[i] ± δ for δ in {0.001, 0.01, 0.1}.
4. Accept any change that strictly lowers C. After one pass, recompute sensitivity and repeat.
5. Run 10 passes or until no improvement in one full pass.

**Hypothesis:**
The TTT-Discover LP algorithm focused on "near-tight constraints" (positions where convolution
is closest to C). The sensitivity map (∂C/∂f[i]) identifies exactly these positions. Coordinate
descent on the top-500 sensitive elements should find micro-improvements that the LP algorithm
left on the table.

**Expected information gain:**
- If it finds improvements: Sensitivity-guided coordinate descent is effective. Use on all
  future published arrays. The sensitive-element set reveals the solution's critical structure.
- If it doesn't: The TTT-Discover array is at a coordinate-wise local minimum. Only global
  methods (SA, LP) can improve it. This is important to know — it tells us the solution
  structure is more complex than element-wise perturbation can resolve.

**Success criterion:** C < 1.50286 after any coordinate change.
**Cost:** Low — about 500 × 3 = 1500 evaluate.py calls, each taking ~0.25s → ~6 minutes. Well
within timeout.

## Experiment 4 — Warm-Start from Cell 47 (N=600, C=1.5053) + Gradient Polish

**Priority: HIGH**

**What to test:**
Extract the Cell 47 array from the AlphaEvolve notebook (600 elements, C≈1.5053). Load as
a starting point for the gradient pipeline. Run the EXISTING best gradient pipeline:
smooth-max Adam T=0.05→0.003→0.0003, 15k steps/phase, multi-seed (4-8 diverse seeds).

**This is different from the failed warm-start experiments because:**
- Cell 47 is at N=600 — our native resolution. No interpolation needed.
- C=1.5053 is at the boundary of our gradient pipeline's capability (best: 1.5090). The basin
  structure at C=1.505 may be different from C=1.503 (where smooth-max Adam is confirmed stuck).
- This is testing whether gradient descent can improve a N=600 published solution, not a 1319+
  element sparse one.

**Hypothesis:**
The pattern_007 failure (smooth-max Adam can't improve published solutions) was observed for
the AlphaEvolve 1319-element array and the upsample-to-2000 variant. Cell 47 at N=600 may
behave differently because: (1) it's at a higher C value where the landscape is less flat,
(2) it's at our optimizer's native resolution. A gradient pipeline optimized for N=600 may
find improvements that LP-guided methods at N=600 didn't.

**Expected information gain:**
- If it improves C below 1.5053: Pattern_007 is resolution-dependent. Smooth-max Adam can
  improve published solutions at N=600 even if not at N=1319+. This opens an entire class of
  warm-start experiments at N=600.
- If it returns to ~1.509: Pattern_007 is general — smooth-max Adam cannot improve any
  published solution regardless of N. The 1.5053→1.5090 drop confirms the 1.509 basin is
  the global attractor for smooth-max Adam.

**Success criterion:** C < 1.5053 (any improvement over the starting point).

## Experiment 6 — Ultra-Conservative Warm-Start at T=0.0001 from TTT-Discover

**Priority: MEDIUM**

**What to test:**
Warm-start from the TTT-Discover 30k array at extreme temperatures:
- T=0.0001 only (single temperature phase, no annealing)
- LR=1e-7 (20× lower than failed attempts)
- 100k steps
- 2 seeds (0 = no perturbation, 1 = tiny Gaussian sigma=0.001 × std(f))

**Hypothesis:**
exploit_1's benchmarking showed that T=0.005 immediately worsens C from 1.503 to 1.519 after
100 steps. But this was for the AlphaEvolve 1319-element array. The TTT-Discover 30k array
has a different structure (mostly uniform low values, gradual rise, terminal spike). It may
be less sensitive to smooth-max approximation error at T=0.0001. At extremely low temperature
and learning rate, the optimizer might make micro-corrections without leaving the basin.

**Caveat:** exploit_1 already showed that the 1.5032 solution is at the smooth-max floor even
at T=0.0001. This experiment tests whether 1.50286 (a better, larger array) behaves differently.

**Expected information gain:**
- If T=0.0001 improves C: The smooth-max floor is array-dependent. The TTT-Discover 30k
  array has slack that the AlphaEvolve 1319 array lacks.
- If it doesn't: Pattern_007 is confirmed for all arrays and all temperatures within the
  smooth-max framework. Move to projected gradient only.

**Success criterion:** C < 1.50280 (meaningful improvement over TTT-Discover baseline).
