## Phase 2: Agent-Reported Doubts Investigation

### Doubt 1: "Are -1e-8 to -1e-9 improvements real or FFT artifacts?" (System Critic gen 7)

**Investigation:** FFT padding validation was Priority 8 in gen 6 recommendations and has never been executed. The improvements are computed by `validate.py` which uses `np.fft.rfft` with zero-padding to `2*N-1`. The FFT itself is numerically stable, but the concern is whether different padding sizes produce different C values at the 9th decimal place.

**Resolution: UNRESOLVED.** Cannot confirm or refute without running the experiment. However, the improvements are consistent across 3 independent agents using different code paths, which provides indirect evidence they are real. Surfaced in State of Affairs Open Questions.

### Doubt 2: "Coordinate descent convergence inconsistency — 40x improvement count discrepancy" (System Critic gen 7, Agent Gaps gen 7)

**Investigation:** exploit_1 found 6551 improvements; exploit_2 found 156; full_1 found 257. All from the same starting point. Root cause identified: different delta grids. exploit_1 used combined absolute + proportional + zeroing grid (comprehensive); exploit_2 and full_1 used primarily absolute grids (narrower).

**Resolution: CONFIRMED — not a bug but a standardization gap.** The 40x discrepancy is explained by different thoroughness of delta grids, not by errors. However, this means convergence claims from exploit_2 and full_1 are premature — they converged to their grid's optimum, not the true coordinate-wise optimum. The true coord-wise optimum is closer to exploit_1's output. This is why the `coordinate_descent.py` helper is the most-requested deliverable.

### Doubt 3: "fact_002 outdated" (Evaluator gen 5, 6, 7; System Critic gen 6, 7; Agent Gaps gen 7)

**Investigation:** fact_002 says "best known bounds 1.28 ≤ C ≤ 1.5098, target C ≤ 1.5053." Current pipeline best: 1.5028628689. Published SOTA (TTT-Discover): ~1.50286. Target beaten since gen 3.

**Resolution: CONFIRMED OUTDATED.** The upper bound should reflect ~1.50286 and the target statement should acknowledge it's been beaten. However, fact files are not in this review's direct output scope (no `output/updated_facts/` directory specified). Flagging for manual update or next evaluator cycle.

### Doubt 4: "pattern_007 duplicate" (Gen 6 consistency review, Gen 7 architect, Gen 7 agent_gaps)
