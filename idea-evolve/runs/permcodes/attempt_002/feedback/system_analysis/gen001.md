# System Analysis — Generation 1

## Pipeline Problems

### 1. Research-to-execution gap (CRITICAL)
**Evidence**: `reports/gen001/research_1.md` identified PGL(2,7) as the single most promising direction (section "Finding 1") with explicit implementation sketch. None of the 4 agents implemented it. The evaluator confirms "the most important direction was identified but not executed" (`evaluator.md:161`).

**Impact**: A critical 310-codeword improvement opportunity (616→926 gap) was fully documented but entirely unexecuted. The research pipeline produced a complete roadmap to a new group action, and zero agents followed it.

**Severity**: Critical — the entire strategic direction for gen 2 was known but not attempted.

### 2. Knowledge base not persisted to knowledge/ (CRITICAL)
**Evidence**: `reports/gen001/evaluator_debrief.md` lines 16-18 explicitly notes:
- "No clusters/ directory files written (cluster definitions not yet in knowledge/clusters/)"
- "No ideas moved to knowledge/ideas/ (all ideas still in output/new_ideas/)"
- "No patterns moved to knowledge/patterns/"

The evaluator created `output/new_ideas/` and `output/new_patterns/` but the orchestrator never moved them to `knowledge/`. The entire generation's knowledge production is invisible to the next generation.

**Impact**: Gen 2 will have the same cold start as gen 1. All 14 ideas and 4 patterns are stranded in evaluator workspace output.

**Severity**: Critical — knowledge produced but not stored. Violates pipeline contract.

### 3. Redundant agent effort on AGL(1,8)
**Evidence**: `coverage_matrix.md` shows "idea_001 alone (AGL orbit clique)" attempted 6 times across 7 solutions. `architect.md:49-58` explicitly flagged homogeneity risk — two of four agents (full_1 and explore_1) both implemented the AGL direction. The evaluator notes this wasted 4 agent-slots that could have been used for PGL exploration (`evaluator.md:91`).

**Impact**: ~50% of agent compute was spent on a direction that was known to be at its limit before gen 1 even started (AGL's 616 is a known lower bound, not a target).

**Severity**: Moderate — AGL thoroughness has value, but redundancy was predictable and avoidable.

### 4. Two solutions crashed with trivial bugs (MODERATE)
**Evidence**: `evaluator.md:39-40`: GA crashed due to `np.array([])` defaulting to float64 when used as indices. ILNS v4 returned all 40320 permutations (timeout/bug). `agent_gaps/gen001.md:84-88` confirms.

**Impact**: 2 of 12 solutions (17%) wasted evaluation cycles on crashes. Neither was a fundamentally bad approach — both had fixable bugs.

**Severity**: Moderate — agents need basic sanity checks before submission.

## Prompt Problems

### 5. Brief target (624) unmotivated and misleading (MODERATE)
**Evidence**: `agent_gaps/gen001.md:33-37` identifies that the brief mentioned target 624 but upper bound is 926 and lower bound is 616. The target is unmotivated.

**Impact**: Agents correctly identified the real situation, but the misleading target could cause a naive agent to stop at 624 instead of pushing toward the true optimum.

**Severity**: Moderate — agents recovered, but prompt accuracy matters for autonomous operation.

### 6. Research agent has no code output requirement (MINOR)
**Evidence**: `agents/research.md` prompt does not require solution code output. The research agent spent significant time on web research and produced only `findings.md` — no solution code. This is expected for research, but means one agent slot produced no evaluable solution.

**Impact**: The research direction was valuable but only one agent (research_1) followed it. Without a solution to evaluate, the research findings depended entirely on another agent picking up the PGL direction in gen 2.

**Severity**: Minor — research is legitimate, but the pipeline should ensure research findings translate to executables.

## Missing Capabilities

### 7. No within-generation knowledge sharing (CRITICAL)
**Evidence**: Multiple agents independently discovered the same AGL baseline. No agent knew what others were doing until after evaluation. `agent_gaps/gen001.md:90-94` confirms: "Agents produced solutions without knowing what other agents tried."

**Impact**: Redundant work, missed collaboration opportunities. This is especially costly in gen 1 where everything is new.

**Severity**: Critical — the pipeline lacks a mechanism for agents to build on each other's partial results mid-generation.

### 8. Compatible-permutation count never run (HIGH)
**Evidence**: `research_1.md:57-58` proposed running `fast_compatible_mask()` on the 616-code to count extra-compatible permutations. `evaluator.md:47-48` calls this "the key empirical question." `evaluator_debrief.md:19` confirms it was never executed.

**Impact**: We don't know if the 616-code has any "nearby" compatible permutations. This is the most important binary decision: are there extendable perms (→ pursue SA/VNS) or is the code truly isolated (→ PGL is mandatory)?

**Severity**: High — blocks informed strategy selection for gen 2.

### 9. No PGL(2,7) elements derived (HIGH)
**Evidence**: `research_1.md:56` and `evaluator.md:49` both confirm: "I don't have the explicit 336-element group as a set of 8-permutations." The research agent described the Möbius transformation construction but didn't implement it.

**Impact**: The most important experiment for gen 2 cannot be run without first deriving PGL elements. This blocker was known but unaddressed.

**Severity**: High — single blocking issue for the top strategic priority.

## Knowledge Quality Issues

### 10. Clusters not persisted (MODERATE)
**Evidence**: `evaluator_debrief.md:15` says "No clusters/ directory files written." The evaluator created preliminary clusters (Algebraic, Stochastic, Helper Techniques) but they're stranded in evaluator workspace.

**Impact**: The cluster structure is lost. The consistency reviewer has no prior cluster definitions to audit or refine.

**Severity**: Moderate — clusters are advisory but provide important knowledge organization.

### 11. State of Affairs written but ideas not accessible (MODERATE)
**Evidence**: `knowledge/state_of_affairs.md` exists and is accurate, but all 14 ideas are in `output/new_ideas/` not `knowledge/ideas/`. The SoA correctly references "idea_001 through idea_014" but these files don't exist in the knowledge base.

**Impact**: Next generation's knowledge dump cannot include these ideas because they're not in the knowledge directory structure.

**Severity**: Moderate — the SoA is accurate but hollow; it's a map with no territory.

## Experiment Gaps

### 12. Five proposed experiments all untested (HIGH)
**Evidence**: `evaluator.md:99-143` proposes 5 specific experiments. `agent_gaps/gen001.md:53-79` lists them as "Not Yet Tested":
1. PGL(2,7) orbit clique search (CRITICAL)
2. Compatible permutation count for 616-code (HIGH)
3. Cross-group PGL × AGL clique search (HIGH)
4. VNS from 616-code seed (HIGH)
5. Bron–Kerbosch on AGL orbit graph (MEDIUM)

None were executed. `research_1.md:86-94` proposes the same 5 experiments with implementation sketches. Zero implementations followed.

**Impact**: Gen 1 established the AGL ceiling but produced no movement toward the ceiling of 926. The pipeline identified exactly what to try and then tried none of it.

**Severity**: High — this is the core productivity gap. Ideas are cheap; experiments are expensive.

---

## Summary

Generation 1 successfully established the baseline: AGL(1,8) orbit clique = 616 is confirmed, is maximal within AGL, and stochastic methods cap at ~293. This is valuable.

However, the pipeline's critical failure is that it identified the path forward (PGL(2,7) orbit construction, with 5 specific experiments) and then executed zero of them. The research-to-execution gap is the single largest problem: the most important direction for the next generation was fully described but completely unattempted.

The second critical problem is knowledge persistence: the evaluator created 14 ideas, 4 patterns, and 3 clusters, and none of them made it into the knowledge base. Gen 2 starts with the same empty knowledge base as gen 1.

The third problem is redundant effort: half of agent compute went to AGL variants despite AGL's limit being a known lower bound before the generation started.
