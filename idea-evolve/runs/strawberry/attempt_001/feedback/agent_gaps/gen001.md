# Agent Gaps — Generation 1

## Missing Information

### 1. No per-class performance data
All agents reported only aggregate mAP50. No one knows which specific disease classes are failing. The 15x class imbalance means Anthracnose and Blossom Blight are likely the bottleneck, but there is no data confirming this. Without per-class mAP, agents cannot target specific weaknesses.

**Recommended action**: Add per-class mAP reporting to evaluate.py or create a helper `evaluate_on_test_per_class()` that returns per-class precision/recall/mAP.

### 2. No test set image visibility
Agents cannot see the test images. They cannot diagnose whether failures are due to small objects, occlusions, lighting, or class confusion. Visual inspection of test predictions would dramatically accelerate debugging.

**Recommended action**: Create a helper that saves test predictions (masks + image) to a directory for later review.

### 3. No understanding of the val-test gap root cause
full_1 observed val=0.91 vs test=0.8137 but could not explain why. Possible causes:
- Test distribution shift (different disease presentation/lighting)
- Overfitting to val during 100-epoch training
- Fine-tuning regime mismatch (20 epochs insufficient for positive transfer)

**Recommended action**: Add a diagnostic experiment: evaluate exp5 best.pt directly on test WITHOUT fine-tuning to establish the zero-shot baseline.

### 4. No knowledge of copy_paste mode variants
All experiments used default copy_paste="flip". The research mentioned copy_paste_mode="mixup" as an alternative, but no agent tested it. The mode may matter more than the probability at high values.

**Recommended action**: Test copy_paste=0.5 with copy_paste_mode="mixup" vs "flip" as a controlled comparison.

## Training Infrastructure Issues

### 5. optimizer=auto silently overrides lr0
This bug (idea_005) affected full_1's experiment. The train_and_eval() helper uses optimizer='auto' by default, which ignores explicit lr0 settings. All agents should be warned about this. The fix is simple (pass optimizer='AdamW') but agents wasted turns discovering it.

**Recommended action**: Either fix train_and_eval() to default to optimizer='SGD' with the provided lr0, or add a clear warning in the helper docstring.

### 6. No training logs visible to agents
When explore_2 got a broken pipe, there were no logs to diagnose whether it was copy_paste, memory, or random failure. Agents are flying blind on crashes.

**Recommended action**: train_and_eval() should save training log to RUN_DIR before cleanup, or print the last 20 lines on error.

## Knowledge Representation Issues

### 7. Baseline solutions not in population/gen000
The baseline sol01 and sol02 from gen_000 are in population/gen000/baseline/ but the orchestrator's solution tracking does not include them in the solution-idea map. The map should include gen_000 as starting references.

### 8. Research findings not consolidated into ideas
research_1 produced 6 detailed findings but only idea_003 (TTA) was captured as an idea. The other 5 (ensemble, progressive resizing, class weighting, label smoothing, NMS tuning) are documented in the research report but not created as idea files. This is a pipeline routing issue — research outputs should be systematically turned into idea files.

### 9. Experiment results older than 3 generations
N/A — this is gen_1. No old experiments to consolidate.

## Process Issues

### 10. One agent crashed without valid score
explore_2 produced no useful data. The broken-pipe issue needs investigation. Was it copy_paste=0.65 specifically, or a random crash that could happen at any value?

### 11. Agents used different starting points inconsistently
- explore_1: yolo11s from COCO (Mode 2)
- explore_2: WEIGHTS_EXP5 (Mode 1)
- full_1: WEIGHTS_EXP5 (Mode 1)

The field is not level — different starting points make it hard to compare results. The system should enforce that探索 agents compare like-to-like unless specifically testing the starting point.

### 12. No TTA applied to ANY solution
Even as a post-hoc boost, no agent applied TTA to the best trained model to get a more accurate fitness signal. This is the simplest possible win and was missed entirely.
