# Experiment Suggestions — Generation 2

## Experiment 1: WEIGHTS_EXP6 vs WEIGHTS_EXP5 Fine-Tune Comparison

### Rationale
The State of Affairs notes WEIGHTS_EXP6 (exp6_combined_aug, val mAP50=0.936) has never been tried as a fine-tuning starting point, while WEIGHTS_EXP5 (val mAP50=0.945) is the confirmed best. exp6 used combined augmentation during training — this may make its feature representations more robust for fine-tuning even though its val score is slightly lower.

### Hypothesis
Fine-tuning from WEIGHTS_EXP6 (combined_aug) will outperform WEIGHTS_EXP5 for the 20-epoch proxy because the combined augmentation trained the model to be more invariant to augmentation variations.

### Method
Run identical fine-tuning configs (copy_paste=0.7, mixup=0.15, lr0=0.0005, 20 epochs) from both WEIGHTS_EXP5 and WEIGHTS_EXP6. Compare:
- Overall mAP50 (primary)
- Per-class mAP50 (which classes benefit more from each starting point)
- Convergence speed (does one reach higher scores faster?)

### Expected information gain
- Whether exp6's combined_aug training produces better fine-tuning starting point
- Which classes prefer which starting point (enables intelligent selection per class)
- If confirmed, WEIGHTS_EXP6 becomes the default starting point for all subsequent experiments

## Experiment 2: copy_paste Sweep with mixup=0.15

### Rationale
Gen 1 tested copy_paste=0.5, 0.6, 0.7, 0.8 with mixup=0.15 only at copy_paste=0.7. The exact optimum is unknown — it could be 0.65 or 0.68. Finer-grained sweep closes this gap.

### Hypothesis
copy_paste=0.65 with mixup=0.15 will outperform both 0.6 (0.8209 at 40 epochs) and 0.7 (0.8296 at 20 epochs), establishing the true sweet spot.

### Method
Fine-tune from WEIGHTS_EXP5 with:
- copy_paste values: 0.55, 0.60, 0.65, 0.70
- mixup=0.15 constant
- lr0=0.0005
- 20 epochs (proxy evaluation)

### Expected information gain
- Exact copy_paste optimum for this problem
- Whether the improvement from 0.6→0.7 continues or saturates
- Guides further augmentation optimization

## Experiment 3: Per-Class Baseline Establishment

### Rationale
No agent knows the per-class mAP50 for WEIGHTS_EXP5. This is a prerequisite for all targeted optimization. Without it, we can't estimate headroom or design class-specific strategies.

### Hypothesis
Angular Leafspot (0.66-0.74 across gen 1) has limited headroom due to inherent visual similarity to other diseases. Leaf Spot (0.76-0.80) may have more headroom. Anthracnose (0.804-0.858) responds well to augmentation.

### Method
Run `evaluate_on_test(WEIGHTS_EXP5)` to get per-class mAP50, precision, recall breakdown. Store in a machine-readable form (LAST_PER_CLASS_METRICS already written, but needs a `get_per_class_metrics()` helper to read it).

### Expected information gain
- Which classes have headroom (close to 1.0 vs stuck at lower values)
- Which classes need fundamentally different approaches vs incremental improvement
- Whether class-specific strategies are warranted

## Experiment 4: yolo11s with Fewer Epochs (Retry After BrokenPipe Fix)

### Rationale

### Expected information gain

- If yolo11s outperforms nano, it becomes the default model for all subsequent experiments

## Experiment 5: 40-Epoch Extended Training on Best Gen-1 Config

### Rationale
Gen 1 full_1's sol02 (copy_paste=0.6, 40 epochs) achieved 0.8209 — only slightly below explore_1_sol04 (0.8296, 20 epochs). The best config (copy_paste=0.7, mixup=0.15, lr0=0.0005) was never tested at 40 epochs.

### Hypothesis
Running the best gen-1 config (copy_paste=0.7, mixup=0.15) for 40 epochs will exceed 0.85 proxy, testing whether the current approach can approach the target (0.92).

### Method
Fine-tune from WEIGHTS_EXP5 with copy_paste=0.7, mixup=0.15, lr0=0.0005, 40 epochs. Compare against:
- gen001_explore_1_sol04 (0.8296 at 20 epochs)
- gen001_full_1_sol02 (0.8209 at 40 epochs with copy_paste=0.6)

### Expected information gain
- Whether more epochs close the gap to 0.92
- Whether 40-epoch training validates the 20-epoch proxy as reliable
- Whether copy_paste=0.7 continues to improve at 40 epochs
