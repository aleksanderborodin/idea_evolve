# Experiment Suggestions — Generation 2

Ranked by expected information gain per evaluation cost. All experiments assume 20-epoch proxy fine-tuning unless noted.

## EXP-1: Zero-shot baseline for exp5 best.pt on test (HIGHEST PRIORITY)

**Hypothesis:** Fine-tuning from exp5 for 20 epochs is neutral or harmful compared to the zero-shot checkpoint. The val-test gap (val=0.91, test=0.8137) suggests exp5 is overfit to val, and 20 more epochs of fine-tuning continues that overfitting without generalizing to test.

**Method:** Evaluate `WEIGHTS_EXP5` on test with `evaluate_on_test(WEIGHTS_EXP5)` — no training, no fine-tuning, pure inference.

**Expected information gain:**
- If exp5 zero-shot ≥ 0.8137: fine-tuning is neutral or harmful → pipeline should explore non-fine-tuning directions (imgsz, TTA, ensembles)
- If exp5 zero-shot < 0.8137: fine-tuning provides positive transfer → continue exploring fine-tuning improvements

**Cost:** ~30 seconds (one evaluation, no training). This is the highest-value experiment per cost in the entire pipeline.

**Why this experiment matters:** It determines whether the entire fine-tuning research direction is viable. Without it, every fine-tuning experiment's results are uninterpretable.

---

## EXP-2: TTA on best gen_1 model

**Hypothesis:** Test-Time Augmentation provides a consistent ~0.5-1% mAP50 lift on top of any trained model at zero training cost.

**Method:** Evaluate `population/gen001/explore_1/sol01.py` (or WEIGHTS_EXP5) with `augment=True` in `model.val()`. Compare against the non-TTA baseline of 0.8328.

**Expected information gain:**
- TTA lift on exp5 fine-tuned model: establishes whether TTA is worth always using
- TTA lift on COCO-trained model: establishes whether TTA compensates for weaker pretraining
- Per-class TTA effect: does TTA help rare classes disproportionately?

**Cost:** ~30-60 seconds (TTA roughly triples inference time). Negligible.

**Why this experiment matters:** TTA is a free lunch. If it works, every future fitness measurement should use TTA. The research_1 agent already provided complete implementation code (research_1.md:28-38).

## EXP-3: yolo11s from exp5 checkpoint (not from COCO)

**Hypothesis:** The best result in gen 1 came from yolo11s starting from COCO (0.8328). Starting from the converged exp5 checkpoint combines the larger model capacity with domain-adapted weights, yielding further improvement.

**Method:**
```python
from helpers.core import train_and_eval, WEIGHTS_EXP5
# yolo11s-seg from exp5, 20 epochs, AdamW, lr0=0.001
# Note: must pass optimizer='AdamW' explicitly to avoid auto-optimizer trap
return train_and_eval(
    model_path=WEIGHTS_EXP5,
    epochs=20,
    lr0=0.001,
    copy_paste=0.5,
    optimizer='AdamW',  # Critical: avoid auto-optimizer override
)
```

**Expected information gain:**
- Does yolo11s benefit from exp5 pretraining more than yolo11n does? (compares to full_1's 0.8137 with nano)
- Does the larger model show positive transfer where nano showed neutral?

**Cost:** ~3.6 minutes (20 epochs, same as gen_1 agents).

**Why this experiment matters:** This is the most logical combination of gen_1's best findings. If it works, the path to 0.85+ becomes clear. If it fails (similar to full_1's 0.8137), the issue is the 20-epoch regime, not the model scale.

## EXP-4: imgsz=832 with exp5 start (addressing the small-lesion hypothesis)

**Hypothesis:** Test images contain smaller or differently presented lesions that are poorly captured at 640px. Higher resolution (832) directly addresses this.

**Method:**
```python
from helpers.core import train_and_eval, WEIGHTS_EXP5
return train_and_eval(
    model_path=WEIGHTS_EXP5,
    epochs=20,
    imgsz=832,
    batch=8,  # reduce batch for larger images
    lr0=0.001,
    copy_paste=0.5,
    optimizer='AdamW',
)
```

**Expected information gain:**
- Does higher resolution close the val-test gap? If test lesions are smaller, 832 should show disproportionately better test improvement vs val.
- Is the 20-epoch regime sufficient for the model to adapt to higher resolution features?

**Cost:** ~3.6 minutes + slightly higher memory usage.

**Why this experiment matters:** Both explore_1 and full_1 independently recommended this as the top unexplored direction. The small-lesion hypothesis is the most plausible explanation for the val-test gap.

## EXP-5: copy_paste=0.6 (fill the gap between 0.5 and 0.65)

**Hypothesis:** copy_paste=0.65 crashes but copy_paste=0.6 might be stable and provide better rare-class handling than 0.5.

**Method:** Use the same config as full_1 (WEIGHTS_EXP5, 20 epochs, AdamW, lr0=0.001) but with `copy_paste=0.6`.

**Expected information gain:**
- Is 0.6 stable? Establishes the actual ceiling for copy_paste.
- If stable, does it improve rare-class mAP (per-class metrics from EXP-2 would tell us)?

**Cost:** ~3.6 minutes.

**Why this experiment matters:** If 0.6 is stable and beneficial, it directly improves the class imbalance strategy. If it crashes, we know the ceiling is between 0.55 and 0.65.

## EXP-6: TTA + imgsz=832 combined (best evaluation protocol)

**Hypothesis:** Combining TTA with higher resolution provides additive or superadditive benefits because they address different failure modes (boundary quality from TTA, small-object detection from imgsz).

**Method:** Take the best trained model from EXP-4 (or EXP-3 if only one can run) and evaluate with `augment=True` at imgsz=832.

**Expected information gain:**
- Does TTA amplify the resolution benefit?
- What is the best achievable score with current models and zero-cost evaluation improvements?

**Cost:** ~60 seconds (evaluation only, assuming EXP-4 produced a model).

**Why this experiment matters:** Establishes the upper bound of what's achievable with existing training regimes. If TTA+imgsz=832 gets 0.85+, the fine-tuning direction is validated. If still below 0.84, the training regime itself needs rethinking.
