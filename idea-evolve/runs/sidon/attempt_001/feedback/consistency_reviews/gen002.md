## Critical Finding: Duplicate/Contradictory Fact Files

**Severity: HIGH.** Two fact files exist in BOTH `facts/` and `ideas/active/` with contradictory content:

| File | `facts/` version | `ideas/active/` version |
|------|-------------------|------------------------|
| `fact_002.md` | Upper bound "~100-102" (WRONG), confidence 0.8, verified: false | Upper bound "~109" (CORRECT), confidence 0.9, verified: true |
| `fact_004.md` | "validator extracts largest valid subset" (WRONG), confidence 0.8, verified: false | "fitness=0 for ANY violations" (CORRECT), confidence 1.0, verified: true |

**Root cause:** The gen 2 evaluator wrote corrected versions to `output/updated_ideas/`, and the
output mover placed them in `ideas/active/`. But the originals in `facts/` were never updated.
Any agent reading from `facts/` gets dangerously wrong information.

**Resolution:** Updated fact files written to `output/updated_ideas/fact_002.md` and
`output/updated_ideas/fact_004.md`. These should replace the versions in `facts/`. The copies
in `ideas/active/` should be removed after `facts/` is updated (facts belong in `facts/`, not `ideas/`).
