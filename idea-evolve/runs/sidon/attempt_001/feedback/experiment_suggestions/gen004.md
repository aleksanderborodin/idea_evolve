## EXP-B: Beam Search Greedy (HIGH)

**Priority**: High. Highest-value untested non-algebraic approach.

**What to do**:
```python
def beam_search_sidon(N, k_beams):
    beams = [([0], set())]  # Each beam: (elements, differences)
    while True:
        candidates = []
        for elems, diffs in beams:
            for c in range(elems[-1]+1, N+1):
                new_diffs = {abs(c - e) for e in elems}
                if not new_diffs & diffs:  # No collision
                    score = -count_blockers(c, elems, diffs)  # min-blocking heuristic
                    candidates.append((score, c, elems[:], diffs.copy()))
        if not candidates:
            break
        candidates.sort(reverse=True)
        beams = [(elems + [c], diffs | new_diffs)
                 for _, c, elems, diffs in candidates[:k_beams]]
    return max(beams, key=lambda b: len(b[0]))[0]
```

Try k_beams = 10, 50, 200. Record best score and runtime for each.

**Expected result**: 75-85 elements. Multiple agents independently estimate this range.

**What we learn**: Whether the greedy ceiling of 69 is specific to greedy (one-beam) or
extends to bounded lookahead. If beam search also plateaus at 69-72, the ceiling is structural.
If it reaches 80+, beam search becomes a key non-algebraic tool.

**Assignment**: Explore agent.

## EXP-F: Stochastic Min-Blocking with Restarts (MEDIUM)

**Priority**: Medium. Non-algebraic exploration with randomization.

**What to do**:
Modify the min-blocking greedy (now confirmed at 69) with stochastic selection:
- At each step, instead of always choosing the min-blocking candidate, choose randomly
  from the top-K candidates (K=5 or K=10) with probability proportional to 1/(rank+1)
- Run 500-1000 restarts
- Record: distribution of scores achieved, best score, mean score

**Expected result**: Distribution around 67-75 with occasional peaks to 72-75. If best
score is ≥75 across 1000 trials, confirms randomized greedy can escape the greedy plateau.

**What we learn**: The exploration value of randomization. If 1000 restarts never exceed
72, confirms the 69-70 ceiling is robust to random tie-breaking. If occasional runs reach
75+, beam search is likely to reach 80+ (beam search = systematic version of this).

**Assignment**: Explore agent.
