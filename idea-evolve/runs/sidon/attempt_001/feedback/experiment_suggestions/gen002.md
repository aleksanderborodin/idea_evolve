# Experiment Suggestions — Generation 3

## Context

Singer constructions are exhausted at 102. The gap to the theoretical bound is 102→109 = 7
elements. Local search (SA, single/pair perturbation) is proven infeasible from the 102-element
seed due to 40+ minimum blockers. Gen 3 must explore fundamentally different approaches.

---

## EXP-1: Literature search — best known Sidon set for N=10000

**Type**: Research (1 agent)
**Priority**: HIGHEST — determines all other strategy

**What to do**: Search for published computational Sidon set tables for N=10000:
1. O'Bryant 2004 survey (arXiv:math/0407117) — Table 1 or appendix may have F(10000)
2. Helm 2006 — computational tables of best known B₂ sets
3. Recent computational results (2010-2025) — search for "Sidon sets", "B₂ sequences",
   "perfect difference sets", "N=10000"

**Hypothesis**: Either (a) 102 matches published best → our result is competitive, future
work should focus on exact optimization; or (b) 103-109 sets are published → their construction
method is the key to closing the gap.

**Information gain**: Highest possible. Without this, all gen 3 strategies are calibrated blindly.
If answer is (b), we immediately know what construction to implement.

**Expected output**: findings.md with the best known F(10000) value and construction (if found).

## EXP-2: Correct Bose-Chowla construction

**Type**: Exploit (1 agent)
**Priority**: High

**What to do**: Implement the actual Bose-Chowla B₂ set construction. NOT the carry-violating
version ({i·p + g^i%p}). The correct version uses a different parameterization:

For a prime p, Bose-Chowla constructs a B₂ set of size p in Z_{p²-1} (or Z_{p²+p+1} in some
formulations). Specifically:
- Let g be a primitive root mod p
- The construction involves elements in Z_{p(p-1)} or similar
- Reference: Bose & Chowla 1962, "Theorems in the additive theory of numbers"

**Hypothesis**: Correct Bose-Chowla for p ≈ 100 may give ~100-101 elements in {0..10000}.
Different algebraic structure from Singer may have different truncation/perturbation properties.

**Information gain**: Confirms or denies whether Bose-Chowla is competitive with Singer q=101.
If competitive, opens hybrid combination approaches.

## EXP-3: Large-k perturbation from 102-element Singer seed

**Type**: Exploit (1 agent)
**Priority**: High

**What to do**: Start from the hardcoded 102-element Singer q=101 set. Remove k=5, 10, 15, 20
elements (try increasing k) and then run exhaustive/intensive greedy search over {0..10000}
trying to build a 103-element Sidon set.

**Rationale**: The 40+ blocker count means any single candidate requires removing 40+ current
elements. But if we PRE-REMOVE k=10-20 elements strategically (choosing which to remove based
on maximizing candidate additions), we might create enough "space" for 103 total.

**Suggested approach**:
1. For k=10: enumerate all C(102,10) = ~10^13 removal sets (too many). Instead: random sample
   or choose k removals targeting high-blocker elements.
2. Better: remove the k "most blocking" elements (those that block the most non-members).
3. After k removals, greedy extend over {0..10000}.
4. Accept if new size > 102 - k + added.

**Hypothesis**: k=10-15 removals + greedy extension = 103-107 elements is plausible if the Singer
set's blocker structure has a small set of "keystone" elements. Low probability per trial but
the search space is tractable with thousands of random removals.

**Expected runtime**: 10000 trials × 0.5s each = ~1.5 hours. Fits in 1800s with fast implementation.

## EXP-4: Ruzsa's actual B₂ construction via Z_p Sidon lifting

**Type**: Research + Exploit (1 agent)
**Priority**: Medium

**What to do**: Research and implement Ruzsa's actual B₂ construction (not the carry-violating
formula). The real Ruzsa construction uses a different approach:
- Start with a Sidon set S in Z_p (the integers mod p)
- Lift to Z via a specific embedding that preserves the Sidon property
- Different papers give different parameterizations — research the original Ruzsa 1993 paper

**Hypothesis**: Ruzsa's construction may give a Sidon set of size comparable to Singer but with
different algebraic structure, potentially allowing hybrid combinations.

**Information gain**: Either confirms Ruzsa ≤ Singer (it's known to be asymptotically equal)
or reveals a different structural configuration that can be perturbed differently.

## EXP-5: ILP formulation for bounded subproblem

**Type**: Exploit (1 agent)
**Priority**: Medium

**What to do**: Formulate Sidon set optimization as an Integer Linear Program (ILP). Instead of
optimizing over all of {0..10000}, consider a smaller subproblem:
- Fix the top-50 elements of the 102-element Singer set
- Optimize the remaining 52 positions from a restricted candidate set
- Variables: x_i ∈ {0,1} for each candidate element
- Constraints: for all a≠b, a+b ≠ c+d (pairwise sum uniqueness, linearized via auxiliary vars)

**Hypothesis**: ILP solvers (SCIP, CBC) can find provably optimal solutions for moderate-size
subproblems. Even if the global ILP is too large, using ILP to optimize a 20-element "free
zone" within the Singer seed could find 103+.

**Practical consideration**: Check if scipy.optimize, PuLP, or SCIP are available in the
environment. If no ILP solver is available, this experiment is infeasible. Report this outcome.

## EXP-6: Singer set gap analysis for higher-k truncation windows

**Type**: Research (can be done in 1-2 hours)
**Priority**: Medium

**What to do**: Analyze the cyclic structure of Singer q=101 to determine:
1. What is the maximum consecutive gap in the Singer q=101 set (in Z_{10303})?
2. This gap defines the minimum window size needed to contain all 102 elements.
3. If gap > 10001: some shifts cannot fit all 102 elements (already known from the 569/10303 figure)
4. More importantly: for Singer sets from larger primes (q=103, 107), compute the maximum gap
   and determine if there's ANY window of size 10001 that could contain all elements.

**Hypothesis**: exploit_1 found that q=103 gives 104 elements but best shift keeps only 102.
Understanding the gap structure would reveal whether different cyclic structure (e.g., for GF(p²q)
or non-prime-power constructions) could give better truncation.

**Expected output**: A small Python script that computes gap distributions for Singer sets with
various parameters. No new score needed — pure analysis.

## EXP-7: Greedy Sidon with algebraic-aware ordering (non-Singer starting structure)

**Type**: Explore (1 agent)
**Priority**: Medium-Low

**What to do**: Instead of random greedy or Singer-seeded greedy, design a greedy ordering that
uses number-theoretic knowledge:
- Order candidates by their "difference density" in {0..10000}
- Prioritize elements that, when added, "block" fewer future candidates
- Use a look-ahead (add element, count how many remaining candidates become blocked)

**Hypothesis**: Standard greedy is myopic — it adds the first valid element regardless of
future impact. A smarter ordering might break the 75 ceiling (ET local maximum) or even
approach the Singer result from a completely different algebraic direction.

**Expected score**: 75-90 is a realistic target. This approach is unlikely to beat 102 but
could find a structurally different 75-90 element set useful for hybrid work.
