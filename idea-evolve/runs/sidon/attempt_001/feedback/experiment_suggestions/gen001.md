## EXP-1: Singer q=101 Cyclic Shift Optimization

**Priority**: CRITICAL — this is the single most important experiment

**Hypothesis**: Among the 10303 cyclic shifts of the Singer q=101 set (102 elements in Z_{10303}), at least one shift places ≥100 elements inside {0..10000}. If so, this directly achieves target=100.

**Rationale**: The Singer set elements are roughly uniformly distributed in Z_{10303}. The window {0..10000} covers 10001/10303 ≈ 97.1% of the group. Expected elements in window: 102 × 0.971 ≈ 99.0. The variance across shifts is nonzero, so some shifts will yield 100+. The expected best-case across all 10303 shifts is approximately 100-101.

**Implementation**:
```python
from helpers.core import find_singer_set  # to be built per REC-1
q = 101
v = q*q + q + 1  # 10303
S = find_singer_set(q)  # 102 elements
best_count, best_shift, best_set = 0, 0, []
for shift in range(v):
    truncated = [(s + shift) % v for s in S if (s + shift) % v <= 10000]
    if len(truncated) > best_count:
        best_count, best_shift, best_set = len(truncated), shift, sorted(truncated)
# Verify validity with is_sidon(best_set)
```

**Expected runtime**: ~0.1 seconds (10303 shifts × simple list comprehension).

**Information gain**:
- If best ≥ 100: target achieved, write the explicit set, celebrate.
- If best = 99: confirms Singer q=101 matches but doesn't exceed current best. Try multiple primitive polynomials (different primitive recurrences for GF(101) may yield different Singer sets with different distributions).
- If best < 99: structural insight — the q=101 Singer sets are denser in the {10000..10302} overflow range than expected; explains why cyclic shifts don't help.

**Assignment**: Dedicated full or exploit agent in gen 2.

## EXP-2: Multi-Polynomial Singer q=101 Search

**Priority**: High — follow-up to EXP-1 if best shift doesn't reach 100

**Hypothesis**: Different primitive polynomials over GF(101) yield different Singer sets in Z_{10303} with different cyclic shift behavior. Some polynomial choices may yield more elements in {0..10000} at the optimal shift.

**Rationale**: The number of primitive polynomials of degree 3 over GF(101) is φ(101³-1)/3 ≈ several thousand. They all produce Singer sets of size 102, but the specific positions differ. If EXP-1 finds 99 (not 100), trying 20-50 different primitive polynomials may find one where the best shift gives 100.

**Implementation**:
```python
q = 101; v = q*q + q + 1
best_overall = 0
for _ in range(50):  # try 50 random primitive polynomials
    S = find_singer_set(q)  # randomized search inside helper
    for shift in range(v):
        count = sum(1 for s in S if (s + shift) % v <= 10000)
        best_overall = max(best_overall, count)
```

**Expected runtime**: 50 × 0.1s per polynomial × (1-5s to find primitive poly) ≈ 5-250s.

**Information gain**: Either finds a 100-element configuration or tightens confidence that Singer q=101 cannot exceed 99 in {0..10000}.

## EXP-3: Exhaustive Blocker Analysis of the 99-Element Set

**Priority**: High — characterizes the 99→100 barrier precisely

**Hypothesis**: The 99-element Singer-perturbation set has a specific structural reason why no element can be added. Identifying the minimum "blocker set" reveals whether targeted swaps can reach 100.

**Implementation**:
```python
# Load the 99-element set S99 from knowledge/seeds/sidon_99.json
# For each non-member x in {0..10000}:
#   blockers[x] = set of s in S99 such that |x - s| is already a difference in S99
#   or equivalently, can_add fails because of s
# Sort non-members by len(blockers[x]) (fewest blockers first)
# For the top-5 non-members (fewest blockers), try:
#   Remove all of x's blockers from S99
#   Greedily extend to find best set of size > 99
```

**Expected runtime**: O(|S99| × N) ≈ 99 × 10000 = 990K operations, <1 second.

**Information gain**:
- Reveals which elements are "hardest" to add and why.
- If min(len(blockers[x])) = 2: removing 2 elements and adding 3 (including x) may reach 100.
- If min(len(blockers[x])) = 5+: simple local swaps won't work; need larger perturbations or different construction.

## EXP-4: Simulated Annealing from 99-Element Seed

**Priority**: High — tests whether 99→100 is search-difficulty or structural ceiling

**Hypothesis**: The 99→100 barrier is a local minimum in search space, not a fundamental limit. Starting SA from the 99-element set (instead of greedy-66) with slow cooling can escape it.

**Setup**:
- Starting state: 99-element Singer-perturbation set
- Move types: (a) swap one element for a random non-member, (b) remove 2, add 2-3 via greedy fill, (c) remove 1, extend with candidates from unused-difference region
- Temperature schedule: T₀ = 1.0, alpha = 0.9999, 500K iterations
- Accept worse moves with probability exp(-ΔE/T) where ΔE = size decrease

**Why different from explore_1's SA attempts**: explore_1 used perturbation search (not true SA) from the Singer set. The SA move set above allows temporary size reductions (accept going from 99 to 98 to find a path to 100), which perturbation search does not.

**Information gain**:
- If reaches 100: SA from algebraic seed is viable; document exact move set and schedule.
- If stuck at 99 after 500K moves: 99 is likely a robust local maximum for this approach; need qualitatively different construction.

## EXP-5: Ruzsa-Lindström Construction for Large N

**Priority**: Moderate — alternative algebraic approach untested

**Hypothesis**: The Ruzsa construction (using Sidon sets in Z_p for prime p) yields sets of size approximately p in {0..p²}, which for p=97 gives ~97 elements in {0..9409} ⊆ {0..10000}. Different from Singer, may offer different local search properties.

**Detail**: Ruzsa's construction: for prime p, S = {a·p + b : a, b ∈ Z_p, b ≡ a² (mod p)} gives a Sidon set of size p in {0..p²+p}. For p=97: 97 elements in {0..9506} — similar size to Singer but different structure.

**Information gain**: If Ruzsa sets have better perturbation properties than Singer, they could be a better seed for local search. If identical performance, confirms Singer is the right algebraic foundation.

## EXP-6: k-opt Local Search (k=5-20) from Singer-99

**Priority**: Moderate — larger neighborhood than current perturbation attempts

**Hypothesis**: The 99-element set has no 1-opt or 2-opt improvements, but may have k-opt improvements for k=5-10 (remove 5-10 elements, re-optimize the remaining set + candidates).

**Why not tried**: explore_1's perturbation removed 1-3 elements. explore_2's 2-opt had bugs. A correct implementation of k=5 perturbation (remove 5, greedy fill from scratch with ordered candidates) has not been attempted from the 99-element seed.

**Expected runtime**: For k=10, there are C(99,10) ≈ 5×10¹² combinations — exhaustive is infeasible. Use random sampling: try 1000 random k=10 removals, greedily fill, keep best. Expected runtime: 1000 × 0.01s = 10 seconds.

**Information gain**: If any random k=10 removal + greedy fill reaches 100: path found, analyze the structure. If none of 1000 trials reaches 100: the 99→100 transition requires more than a 10-element perturbation of the Singer base.
