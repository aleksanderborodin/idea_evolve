# Agent Gaps — Generation 5

## Cross-Agent Observations

### 1. Duplicated Work: experimentator_1 and research_1

Both experimentator_1 and research_1 independently downloaded the same Rokicki-Dogon
database and produced identical solutions (105-mark and 104-mark sets). While the
independent verification is valuable, this represents ~50% redundancy. The Architect
assigned both agents to the same highest-priority task without differentiation.

**Recommendation**: When assigning the same database/download task to two agents, give
the second agent a distinct follow-up task (e.g., "if database yields 105, immediately
attempt perturbation/extension search").

### 2. explore_2 Wasted on Naive Bose-Chowla

explore_2 attempted the naive Bose-Chowla formula S = {i*p + (i² mod p)} which is known
to be invalid for large primes (as previously discovered in gen 4 with p=101). The State
of Affairs explicitly notes "Ruzsa quadratic construction FAILED." explore_2 either didn't
read this or misidentified the formula as distinct from Ruzsa's.

**Knowledge gap**: The distinction between the naive quadratic formula (invalid for large p)
and the actual finite field Bose-Chowla construction (used by Rokicki-Dogon) is not clearly
documented in any idea file. idea_004 mentions the parabola failure but doesn't explain
WHY it fails for large primes.

### 3. CP-SAT Compute Budget Insufficient

full_1 spent its entire session on CP-SAT k=103, running three 600s phases. All returned
UNKNOWN. The small-N analysis (proving Singer suboptimal for q=7, q=11) consumed additional
time. The session timeout (~2700s) is fundamentally insufficient for ILP at N=10000 — the
solver needs hours, not minutes.

**Recommendation**: Consider running CP-SAT as a background process with a 4-hour budget
outside the normal agent session framework. Alternatively, use an experimentator to set up
a long-running solver job that writes results to a file for later collection.

### 4. Beam Search Not Seeded from Algebraic Base

explore_1 ran beam search starting from scratch ([0]) for all 7 variants. None tried
starting from the ET(71) 75-element set or the Singer 102-element set. Beam search from
algebraic seeds could potentially extend them by finding elements that the greedy scan misses.

**Knowledge gap**: The brief suggested beam search from scratch. Future briefs should
explicitly suggest algebraic-seeded beam search variants.

### 5. Missing Helper: greedy_extend()

Both research_1 and experimentator_1 reports note the absence of a `greedy_extend(S, N)`
helper. This function (check if any element can be added to a Sidon set) is reimplemented
by nearly every agent. Centralizing it in `helpers/core.py` would save significant time.

### 6. No Agent Tested Perturbation of 105-Mark Set Beyond k=2

experimentator_1 tested remove-and-extend perturbation for k=1 (2000 trials) and k=2 (2000
trials). No agent tested k=3,4,5 or higher. The 105-mark set has different structural
properties than Singer q=101 — the perturbation landscape may be different. Pattern_009
(perturbation futility) was established for Singer sets only, not for Bose-Chowla sets.

### 7. Upper Bound Precision Unknown

research_1 notes the Carter-Hunter-O'Bryant upper bound is "~109-114" for N=10000 but
cannot pin down the exact value without reading the full paper. This 5-element uncertainty
matters: if the true upper bound is 109, we're 4 away; if it's 114, we're 9 away.

**Recommendation**: A research agent should download the full paper (arXiv:2310.20032)
and compute the exact upper bound for N=10000.
