# Agent Gaps — Generation 3

## 1. Missing exploit_1 report
exploit_1 produced sol01.py but no debrief report in `reports/gen003/`. The solution was
evaluated (score 102) but the agent's analysis, observations, and strategic recommendations
are lost. This is a knowledge capture failure.

## 2. Missing explore_1 report
explore_1 produced two solutions and scored one (sol01=63) but no debrief report. The agent's
reasoning about the probabilistic alteration approach and the min-blocking greedy concept
is unrecorded. The min-blocking greedy (sol02) timed out during evaluation — we don't know
if the agent was aware this would happen.

## 3. Research agent terminated prematurely (3rd consecutive failure)
research_1 was terminated before completing any web searches. This is the third generation
in a row that the literature search for F(10000) has failed. The agent identified the right
targets (arXiv papers, OEIS, Helm database) but couldn't execute. The research task needs:
- More time allocation (30-45 minutes minimum, per agent's own assessment)
- Incremental output (save partial findings after each search query)
- Priority within the first 10 minutes of session

## 4. Experimentator helpers not yet deployed
Experimentator_1 built and tested `find_optimal_shift` and `analyze_blockers` helpers in
`output/helpers/optimal_shift.py`. These are validated (9 tests passed) but deployment to
`problem/helpers/` depends on the orchestrator's output move pipeline. Future agents should
check if these helpers are available.

## 5. ILP approach untested
explore_2 attempted ILP but the quadruple-constraint formulation generated 661,650 constraints
for M=200 — far too many for CBC solver. The agent correctly identified that a difference-
indicator formulation would be much better but didn't have time to implement it. ILP has
been identified as highest priority in 3 consecutive generations but never successfully tested.

## 6. Inconsistency in fact files
Architect report notes fact_002 and fact_004 exist both in `knowledge/facts/` (wrong versions)
and in `knowledge/ideas/active/` (corrected versions). Agents reading from `facts/` directly
still get outdated information. The file inconsistency needs to be resolved.

## 7. explore_2 produced bug in sol02
The LNS implementation had a `_build_used_diffs` function that didn't use `abs()` for
unsorted sets, producing 7 violations. sol03 fixed this. This suggests the agent was iterating
too quickly without proper validation between solutions.

## 8. Coverage gap: ILP and constraint programming
No idea file exists for ILP/constraint programming approaches. This is the most-recommended
approach across 3 generations but has no formal representation in the knowledge base. Should
be created as a high-priority idea in gen 4.

## 9. explore_1/sol02 computational infeasibility
The min-blocking greedy is O(N² * steps) per seed, making it infeasible at N=10000. The
agent should have tested at smaller N first or estimated the runtime. This wasted an
evaluation slot and produced no usable data.
