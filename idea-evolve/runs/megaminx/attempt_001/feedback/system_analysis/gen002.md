### MODERATE: String Replacement Footgun Not Documented

**Evidence (from explore_2/sol04):**
- String `.replace()` on dot-joined paths creates empty move names at pattern boundaries
- `U.-U.-U` replacing `U.-U` gives `.-U` → splits to `['', '-U']` → `unknown move '-'`
- All agents discovered this independently; it's not in helper docs

**Severity:** MODERATE — preventable with a single warning in helpers/README.md.
