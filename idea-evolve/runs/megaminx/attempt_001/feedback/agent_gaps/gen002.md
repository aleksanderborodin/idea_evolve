# Agent Gaps — Gen 002

## Identified Gaps

### Gap 1: No Solution Has Tested Trained MLP Predictor (idea_008)

**Severity:** CRITICAL
**Gap:** Every solution in gen_002 that attempted beam search used either unguided search
or hamming predictor (debunked). No solution ran the complete trained-predictor pipeline.
research_1 confirmed the ML pipeline is functional but no agent executed it.

**Evidence:**
- exploit_1 attempted hamming-guided search → 46312 (no improvement)
- explore_1 attempted hamming-guided search → 46312 (no improvement)
- All explore_1 beam attempts used hamming, not trained models

**Required action:** gen_003 must have at least one agent that:
1. Generates training data via `graph.random_walks(50000, 20, mode='bfs')`
2. Trains an MLP predictor on that data
3. Runs `graph.beam_search(predictor=predictor)` on hard/very_hard buckets
4. Compares results to 44114 compression floor

### Gap 2: Compression + Beam Search Not Combined

**Severity:** HIGH
**Gap:** gen_002 solutions either did pure compression OR pure beam search.
No solution combined identity-based compression (44114 floor) WITH beam search to
further improve the compressed paths.

**Evidence:** All explore_2 solutions achieved 44114 via pure compression.
All exploit_1 and explore_1 beam solutions fell back to compression without improving.

**Required action:** Next beam search solutions should:
1. Apply empirical identity compression to get baseline paths (compression_ratio ~0.8723)
2. Use those paths as starting point for beam search
3. Compare beam-searched paths to compressed paths

### Gap 3: experimentator_1 Produced No Output

**Severity:** MEDIUM
**Gap:** The experimentator_1 agent directory is empty. No experiment results,
no helper tools, no findings. The experimentator role was unused.

**Evidence:** experimentator_1/ directory has no files.

**Required action:** Architect should plan experimentator tasks with specific,
actionable experiments. The gen_002 experimentator was not engaged.

### Gap 4: Beam Parameterization Not Explored with Trained Predictor

**Severity:** HIGH
**Gap:** research_1 found beam_width must be 4x-32x larger than gen001 used, but
no solution tested with a trained predictor. We don't know what beam parameters
work when the predictor is actually informative.

**Evidence:** research_1's beam width findings were based on unguided/hamming search.
With a trained predictor, the optimal beam width/splits may differ.

**Required action:** gen_003 should test:
- beam_width=[1024, 2048, 4096, 8192] with trained predictor
- max_steps=[40, 80, 120, 200]
- per-bucket parameter strategies like gen_001 attempted

### Gap 5: idea_007 (Corner PDB) Invalidated — No Replacement Heuristic

**Severity:** MEDIUM
**Gap:** idea_007 was invalidated by gen_002's discovery that all Megaminx generators
are 5-cycles. The IDA* approach in explore_1/sol01 confirmed this. But no alternative
heuristic for IDA* was proposed.

**Evidence:** explore_1/sol01's IDA* attempt failed due to incorrect corner/edge
classification assumptions.

**Required action:** Either:
1. Propose a reformulated pattern database based on correct Megaminx structure, OR
2. Archive idea_007 and focus resources on predictor-guided beam search

### Gap 6: String Replacement Footgun Not Captured in Helper Docs

**Severity:** MEDIUM
**Gap:** explore_2/sol04 tried string replacement and FAILED because it creates empty
move names at pattern boundaries. This is a known danger but it's not documented in
the helper documentation.

**Evidence:** sol04 error: `unknown move '-'` — the string replacement created a
path that split to `['', '-U']`.

**Required action:** Document in helpers/core.py or helpers/README.md:
"NEVER use string replacement for move sequences. Use move-list manipulation:
split → apply rules → join."

### Gap 7: eval_hooks.py Not Updated for Megaminx

**Severity:** LOW
**Gap:** The strawberry problem has `eval_hooks.py` with GPU lock and kill hook.
Megaminx doesn't have an eval_hooks.py, so there's no diagnostic capture on failure.
If a solution crashes, there's no `log_path` in the `.score` file.

**Evidence:** No `/tmp/idea_evolve_megaminx/` diagnostic path or kill hook.

**Required action:** Create `problems/megaminx/eval_hooks.py` similar to strawberry's,
but for now the system works without it.
