## Research Breakthroughs

research_1 produced findings that could fundamentally change the approach:

1. **Wrong model architecture identified** (Finding 1): The raw integer MLP treats
   permutation positions as ordinal values. An embedding-based MLP achieves 5.3x lower loss.
2. **Built-in MITM+beam discovered** (Finding 2): CayleyPy has `bfs_result_for_mitm`
   parameter that enables meet-in-the-middle search automatically. Never used by any agent.
3. **BFS depth 6 = 19.4M exact training samples in 1s** (Finding 3): Replaces noisy
   random walks with perfectly clean distance labels. 24x more data.
4. **Memory-efficient embedding model** (Finding 4): Embedding model avoids 10.9 GB OOM
   from one-hot encoding during beam search inference.
5. **Combined recipe** (Finding 5): Complete end-to-end pipeline combining BFS training +
   embedding MLP + MITM beam search + compression fallback. The top priority for gen004.
6. **Interactive BFS and MeetInTheMiddle** (Findings 9-10): CayleyPy has bidirectional
   search support via `MeetInTheMiddle.find_path_between` for optimal solving up to depth ~20.
7. **Hasher compatibility requirement** (Finding 2): BFS and beam search MUST use the same
   CayleyGraph instance, or MITM silently fails. Critical footgun documented.

## Strategic Assessment

**The compression era is over.** Gen 3 confirms the compression ceiling at ~44114. The
20-move improvement from predictor tail search is negligible. The system must pivot to
the combined recipe (idea_013) which combines three verified-but-uncombined advances:
BFS training data (idea_010), embedding architecture (idea_011), and MITM backstop (idea_012).

**The agent productivity problem is critical.** 3/5 agents producing zero output is
unsustainable. The failure pattern is consistent: agents given complex, open-ended
implementation tasks timeout without producing anything. Future briefs must be staged
and incremental.

**The gap to target (15000) remains massive.** 44094 is still 2.9x the target. Even
the combined recipe may only reach 35000-40000 optimistically. The system needs to
consider whether the current approach can ever reach 15000 or if fundamentally different
paradigms (GNN predictors, reinforcement learning, access to Kaggle solution code) are needed.
