# Megaminx Has Valid Commutator/Conjugation Identities — But They Must Be Discovered Empirically

## Observation

**Confirmed by 6 solutions in gen_002:** Megaminx's Cayley graph permits algebraic
identities beyond X.-X cancellation:

1. **Conjugations (X.Y.X⁻¹ → Y):** Many observed in sample_submission paths. The effect
   of X.Y.X⁻¹ on the solved state equals Y alone. This is non-trivial because Megaminx
   is non-commutative — the conjugation property does NOT follow from basic group theory
   the way it does for abelian groups.

2. **Commutators (X.Y.X⁻¹.Y⁻¹ → identity):** Many observed patterns where the commutator
   of two generators equals the solved state (identity). This provides 4-move→empty
   compression.

3. **Span-2 overlaps (X.-X.Y → Y):** Adjacent cancellation across a move — X.-X followed
   by Y simplifies to just Y. This extends basic X.-X cancellation.

## Key Constraint

**These identities must be discovered empirically**, not enumerated systematically.
gen002_explore_2_sol01 (empirical, 336 rules) → 44114
gen002_explore_2_sol02 (systematic, 432 rules) → 44118 (worse)

Systematic enumeration of ALL valid commutators/conjugations adds noise (rules that don't
appear in test paths). Rules observed in sample_submission paths are more valuable because
they reflect the actual generation process.

## Why This Matters

The pattern confirms that idea_005 (commutator/identity discovery) is REAL and valuable.
But the approach matters: empirical discovery from sample_submission outperforms
systematic algebraic enumeration.

## Limitation

These identities were mined from the specific random-walk-generated paths in the
sample_submission. Their generalization to different puzzle generation processes
is unknown. For this competition, the test puzzles were generated by the same random-walk
process, so the identities apply.
