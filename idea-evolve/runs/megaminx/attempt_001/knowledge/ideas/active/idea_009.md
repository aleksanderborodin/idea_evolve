# Empirical Algebraic Identity Compression

## Summary

Discover valid Megaminx-specific rewrite rules (commutators, conjugations, cancellations)
by empirically scanning sample_submission paths for subsequences that simplify to identity
or shorter forms. Apply the verified rules to compress paths beyond basic X.-X cancellation.
Best result: **44114** (compression_ratio=0.8723) — 2198 points better than baseline 46312.

## How It Works

1. Enumerate all length-2 to length-5 subsequences from sample_submission paths
2. For each subsequence pattern, apply it to the solved state and check: does it equal
   identity? Does it equal a simpler generator?
3. Verified rules include:
   - **X.-X cancellation** (baseline): X followed by inverse → delete both
   - **X.X → identity**: Double move equals solved state (no, all generators are 5-cycles)
   - **X.Y.X⁻¹ → Y** (conjugation): If applying X.Y.X⁻¹ to solved gives same as Y alone
   - **X.Y.X⁻¹.Y⁻¹ → identity** (commutator): ABA⁻¹B⁻¹ = e
   - **X.-X.Y → Y** (span-2 overlap): X.-X followed by Y simplifies to Y
4. Apply rules iteratively with move-list manipulation (NOT string replacement)

## Key Discovery

**Megaminx has valid algebraic identities beyond X.-X that are NOT the standard
Rubik's cube commutators.** The non-commutative geometry still permits:
- Conjugations: X.Y.X⁻¹ → Y (valid in Megaminx Cayley graph)
- Commutators: X.Y.X⁻¹.Y⁻¹ → identity (valid)

This is non-trivial because Megaminx is non-commutative. The identities were discovered
empirically from actual paths, not derived from algebraic first principles.

## Compression Ceiling

~44114 (compression_ratio=0.8723). Achieved by sol01 with 336 empirically observed rules.
Additional systematic rules (432 vs 336) did not improve — the test-set-specific rules
are more valuable than all mathematically valid rules.

## When It Helps

Always useful as a baseline before beam search. The rule set provides ~4.7% additional
compression beyond X.-X cancellation (44114 vs 46312). This is the new floor for
compression-only approaches.

## Limitations

The identities were discovered from sample_submission paths (random walks). Whether
they generalize to different puzzle configurations is unknown. For the competition,
the test puzzles were generated by the same random-walk process, so the rules apply.

String replacement is DANGEROUS — it creates empty move names at pattern boundaries.
Always use move-list manipulation (split → apply rules → join).

## Status

ACTIVE. Established by 6 solutions with consistent results. The ceiling (~44114) is
confirmed — compression alone cannot reach the 15000 target. Beam search + trained
predictor is the next step.
