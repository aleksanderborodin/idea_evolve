# Observations — gen002_explore_2

## Approaches Tried

### sol01: Empirical Pattern Mining (336 rules) → 44114 ✓ BEST
**Approach**: Discovered patterns from sample_submission by:
1. Enumerating all subsequences of length 2-5 from sample_submission
2. Checking which subsequences equal identity or simplify
3. Finding commutators (ABA^{-1}B^{-1} -> identity), conjugations (ABA^{-1} -> B), and double cancellations (XX -> identity)
4. Sorted by count × savings and applied all rules in sequence

**Key discovery**: Many commutators and conjugations in sample_submission paths DO equal identity or simpler forms in Megaminx. This is non-trivial because Megaminx is non-commutative.

**What worked**: The empirical approach (mining from sample_submission) was better than purely systematic enumeration. The 336 rules found were all observed in practice, giving high confidence they apply to the test set.

### sol02: Systematic Commutator Enumeration (432 rules) → 44118
**Approach**: Same as sol01 but with systematic enumeration of ALL commutators/conjugations (not just those observed in sample_submission).

**Result**: Slightly worse (44118 vs 44114). The extra systematic rules (not observed in sample_submission) were noise that didn't help compress the test paths.

### sol03: Combined Systematic + Empirical → 44118
Same as sol02, combined with empirical patterns.

### sol04: String Substring Replacement → INVALID
**Approach**: Tried to apply identity rules via string `.replace()` on the dot-joined path string.

**What failed**: String replacement creates empty move names when patterns appear at boundaries. E.g., replacing `U.-U` in `U.-U.-U` gives `.-U` which splits to `['', '-U']`. This corrupted paths. **Never use string replacement for move sequences.**

### sol05: Systematic Rules + Move-List Application → 44118
Same systematic enumeration as sol02 but with move-list application (not string replacement).

### sol06: Pure Empirical Internal-Cancellation Mining (1832 rules) → 46312
**Approach**: Looked for patterns that have INTERNAL X.-X cancellation (i.e., the pattern itself can be shortened).

**What failed**: This is useless - any pattern with internal cancellation would already be cancelled by the standard X.-X pass. This approach found patterns but they provided no additional compression beyond what X.-X already gives. The 1832 rules were noise.

### sol07: Extended Span-6 Patterns (888 rules) → 44114
**Approach**: Extended sol01's approach to span-6 patterns.

**Result**: Matched sol01 (44114). The additional span-6 patterns didn't help - they were too specific to the training data.

### sol08: Bucket-Aware Compression → 44114
**Approach**: Same rules but applied uniformly to all buckets.

**Result**: Matched sol01 (44114). The bucket-aware approach didn't help - the rules are universally applicable.

## Key Findings

1. **Megaminx has valid algebraic identities beyond X.-X**. Commutators (ABA^{-1}B^{-1}) and conjugations (ABA^{-1}) are valid in the Megaminx Cayley graph and provide additional compression.

2. **Compression ceiling is ~44114 (4.7% below baseline 46312)**. This is the floor achievable with algebraic identity-based compression. The gap to target (15000) is still ~29K — compression alone cannot reach the target.

3. **Empirical discovery > systematic enumeration**. Rules observed in sample_submission are more valuable than all mathematically valid rules. The test set was generated by random walks, so patterns in the paths reflect the generation process.

4. **Span matters, but only up to a point**. Span-4 and span-5 patterns work. Span-6 adds little. Beyond span-6, patterns become too specific.

5. **String replacement is dangerous for move sequences**. Always use move-list manipulation (split → apply rules → join).
